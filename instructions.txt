STEP 1 — PROJECT SETUP
-------------------------------------------------------------

Run these commands:

  npm create vite@latest datagod-frontend -- --template react
  cd datagod-frontend
  npm install
  npm install tailwindcss autoprefixer postcss
  npm install axios
  npm install recharts
  npm install mermaid
  npm install react-grid-layout
  npm install react-router-dom
  npx tailwindcss init -p

In tailwind.config.js set:
  content: ["./index.html", "./src/**/*.{js,jsx}"]

In index.css add:
  @tailwind base;
  @tailwind components;
  @tailwind utilities;

STEP 3 — COMPONENT DETAILS
-------------------------------------------------------------

### ChatWindow.jsx
- Shows list of messages (user + agent)
- Auto-scrolls to bottom on new message
- Shows a "DataGod is thinking..." animated dots when loading
- Each message can contain: text, SQL block, chart, flowchart, table
- State: messages = [{role, content, type, data}]

### MessageBubble.jsx
Props: { role, content, type, data }
- If role = "user" → right aligned, blue bubble
- If role = "agent" → left aligned, white bubble with DataGod avatar
- If type = "chart" → render <ChartRenderer data={data} />
- If type = "flowchart" → render <FlowchartRenderer code={data} />
- If type = "sql" → render <SQLPreview sql={data} />
- If type = "table" → render an HTML table from data
- If type = "alert" → render a red alert banner

### InputBar.jsx
- Text input field (full width)
- Send button (on click + Enter key)
- Microphone button (calls useVoiceInput hook)
- When voice is active: mic button turns red + pulses
- On submit: calls api.sendMessage(text)

### SQLPreview.jsx
Props: { sql }
- Dark code block showing the SQL
- "Run Query" button (green)
- "Edit" button (lets user modify SQL before running)
- Copy to clipboard button
Style: dark background, green text like a terminal

### ChartRenderer.jsx
Props: { chartType, data, title }
- chartType can be: "bar", "line", "pie", "scatter"
- Use Recharts for all chart types
- Include chart title
- Include export button (PNG download)
- Bar: BarChart from recharts
- Line: LineChart from recharts
- Pie: PieChart from recharts
- Scatter: ScatterChart from recharts

### FlowchartRenderer.jsx
Props: { mermaidCode }
- Use mermaid.js to render the diagram
- useEffect to initialize mermaid on mount
- Wrap in a scrollable div
- Include download as SVG button

### Sidebar.jsx
- Left panel (collapsible)
- Two tabs: "History" and "Favorites"
- Each item shows: query text (truncated), timestamp
- Click → reruns the query
- Star icon → adds to favorites
- Trash icon → deletes from history
- Store in localStorage

### Dashboard.jsx
- Grid layout using react-grid-layout
- Each pinned chart is a draggable/resizable card
- Card header: chart title + unpin button + export button
- Empty state: "No charts pinned yet. Ask a question and pin charts here."
- Auto-refreshes all charts every 60 minutes

### ExportButton.jsx
Props: { type, data, filename }
- type = "png" → downloads chart as image
- type = "csv" → converts data to CSV and downloads
- type = "pdf" → opens print dialog with just the chart

### useVoiceInput.js (custom hook)
- Uses window.webkitSpeechRecognition
- Returns: { transcript, isListening, startListening, stopListening }
- Language: 'en-IN' (Indian English)
- Continuous: false (single query mode)

### api.js (all backend calls)
Base URL: http://localhost:8000

Functions to implement:
  sendMessage(message, sessionId) 
    → POST /chat { message, session_id }
    → Returns { response, type, data, sql }
  
  getHistory(sessionId)
    → GET /history/{session_id}
  
  getSchema()
    → GET /schema
  
  pinChart(chartData)
    → POST /dashboard/pin { chart_data }
  
  getDashboard()
    → GET /dashboard
  
  exportCSV(queryData)
    → POST /export/csv { data }
